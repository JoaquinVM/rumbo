# Rumbo

App de finanzas personales que responde una pregunta: a este ritmo, ¿a dónde llego?

- App publicada: https://rumbo.jviscafe.com (entra quien apruebe Cloudflare Access). El artifact privado
  https://claude.ai/artifact/Pa47kuqzy96qmKqbB6Bc5z se dejó de usar.
- Despliegue: `docs/DESPLIEGUE.md`
- Requisitos: `docs/REQUISITOS.md`
- Pruebas: `npm run verificar` (página) y `npm run probar-servidor` (servidor, con Postgres)
